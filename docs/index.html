# ದ್ವಿಮಾನ ಹುಡುಕಾಟ, ಪೈಥಾನ್ ನಲ್ಲಿ

    ಕೆಳಗಿನ, ಮೇಲಿನ = 0, ಉದ್ದ(ಮೌಲ್ಯಗಳು) - 1
    ಆಗ ಕೆಳಗಿನ <= ಮೇಲಿನ:
        ಮಧ್ಯ = (ಕೆಳಗಿನ + ಮೇಲಿನ) // 2
        ಆದರೆ ಮೌಲ್ಯಗಳು[ಮಧ್ಯ] == ಕೀಲಿ:
            ಹಿಂತಿರುಗಿ ಮಧ್ಯ
        ಆದರೆ ಮೌಲ್ಯಗಳು[ಮಧ್ಯ] < ಕೀಲಿ:
            ಕೆಳಗಿನ = ಮಧ್ಯ + 1
        ಇಲ್ಲದಿದ್ದರೆ:
            ಮೇಲಿನ = ಮಧ್ಯ - 1
    ಹಿಂತಿರುಗಿ -1
